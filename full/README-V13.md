# LUDO EDUKASI — SUNNY MOTION V13

## Visual direction
Bright, energetic, playful, premium, mobile-first. No dark dashboard theme.

## Main visual changes
- Bright cream/sky classroom palette
- Board-first composition
- Dedicated unobstructed dice console
- Animated dice orbit around the outside perimeter of the Ludo board after pressing
- Lightweight floating/sparkle/ring animations
- Stronger touch feedback and visual hierarchy
- Existing game interface, question bank and gameplay remain connected to the original JavaScript.

## Important
Open `index.html` from the extracted folder or deploy the folder root to GitHub Pages.

The orbit animation is visual-only. Existing `roll()` remains responsible for the actual game state, question selection and scoring.
